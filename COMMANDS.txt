====================================================================
SETUP COMMANDS (First Time Only)
====================================================================

1. Navigate to project:
   cd "C:\Users\aarju\Downloads\ML Project"

2. Create virtual environment:
   python -m venv venv

3. Activate virtual environment:
   venv\Scripts\activate

4. Upgrade pip:
   pip install --upgrade pip

5. Install dependencies:
   pip install -r requirements.txt

6. Train URL model:
   python training\train_url_model.py

7. (Optional) Train message model:
   python training\train_message_model.py

====================================================================
RUN APPLICATION
====================================================================

Manual:
   cd "C:\Users\aarju\Downloads\ML Project"
   venv\Scripts\activate
   streamlit run app.py

Automated:
   Double-click START_APP.bat

With different port:
   streamlit run app.py --server.port 8502

====================================================================

====================================================================
TROUBLESHOOTING COMMANDS
====================================================================

If port busy, check processes:
   netstat -ano | findstr :8501

Kill process (replace PID):
   taskkill /PID <PID> /F

Reinstall dependencies:
   pip install --force-reinstall -r requirements.txt

Update scikit-learn:
   pip install --upgrade scikit-learn

Clear Python cache:
   del /s /q *.pyc
   for /d /r %i in (__pycache__) do @rmdir /s /q "%i"

====================================================================
DATABASE COMMANDS
====================================================================

View database (SQLite):
   sqlite3 detection_history.db
   .tables
   SELECT * FROM detections LIMIT 10;
   .exit

Backup database:
   copy detection_history.db detection_history_backup.db

Delete database:
   del detection_history.db
